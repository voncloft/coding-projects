Changes verified
- Five-card draw: select replacement cards, then left-click the empty table
  felt to confirm. No selection keeps all five cards. The existing button
  remains available; clicking a card only changes the selection.
- Every poker variant: with no chips selected, a felt click calls what is owed
  or checks when nothing is owed. Selected chips still confirm calls, raises
  and all-ins, while incomplete amounts remain selected for correction.
- Blackjack: left-click the table felt to Hit, right-click it to Stand.
  Betting chips still use left-click to add and right-click to remove.
  Card hit areas and hand navigation controls do not trigger these actions.
- Table prompts and How to play explain the gestures. All prompts are painted
  within the existing table, so table geometry stays unchanged.
- Existing turn, pause, modal-dialog, animation and network action guards apply.
  Clients use the existing host-validated actions; protocol remains 10.
- Game rules and computer decision code are byte-for-byte unchanged from 1.0.15.
  House loans, debt, betting rules, payouts and profiles remain intact.

Regression coverage
- Local draw selects, deselects, replaces zero/two/five cards and verifies
  only selected cards change, one deal event per replacement, and one turn
  advance. Right clicks, outside-felt clicks, pause and other turns do not act.
- Local call/check runs in draw, both stud variants and hold'em, including
  jacks-to-open variants. Tests verify exact payment, no payment on checks,
  rejection of incomplete selected chips and preservation of card clicks.
- Animated blackjack verifies betting-chip removal, automatic deal, felt Hit
  and Stand, blocked early/repeated clicks during dealing, pause and cards.
  Split-hand navigation also ignores right-clicks instead of standing.
- Real client windows over TCP loopback call/check in every poker variant,
  confirm draw replacements and Hit/Stand in blackjack. Tests cover blocked
  host input and other players' turns.
- The audio capture explicitly cashes out after its final hand so automatic
  house loans/next-hand antes cannot contaminate settlement-only cue ordering.
